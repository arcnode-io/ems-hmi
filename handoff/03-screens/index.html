Screens

The designer's working mocks, organized by screen × breakpoint. Each mock renders both themes (Sovereign + Solarpunk) side-by-side. Treat them as the visual contract — when the engineer's output doesn't match these (modulo platform compositing quirks), the handoff failed. Phone mocks use a 380×820 viewport; desktop mocks use 1280×720.
